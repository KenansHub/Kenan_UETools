# Kenan Tools

可迁移的 Unreal Editor 工具插件。当前第一个工具是 `SmoothNormalBaker`：

- 支持 Static Mesh 与 Skeletal Mesh；
- 将焊接位置后的平滑法线转换到原始切线空间；
- 使用八面体编码写入一个可选 UV 通道；
- 默认生成副本，原地覆盖需要二次确认；
- 曲率计算保留为独立接口，v1 不写入网格。

窗口本身是基于 UE 官方 `IModularFeatures` 的轻量工具宿主。具体工具通过 `IKenanEditorTool` 自注册，后续轻量工具可以留在当前模块，重依赖工具可以放入独立 Editor 模块，而不修改宿主窗口。

完整扩展合同、目录职责和新增工具步骤见 [架构与扩展指南](Docs/Architecture.md)。

## 兼容性

源码以 UE 5.4–5.6 的公开 `MeshDescription` 与 Editor API 为兼容目标。当前已在 UE 5.6.1 完成真实编译与 Static Mesh 资产测试；未在对应引擎实际编译的其他版本不视为已验证。

每个工具采用 `Core / Editor / Compat（按需）` 三层职责，另按风险建立 `Tests`。版本判断只进入工具自己的 `Compat`；算法核心不得引用项目、角色、UI、资产保存或引擎私有头。

## 使用

编译并启用插件后，从 `Tools -> Kenan Tools` 打开窗口。先用 `从内容浏览器读取选择` 获取目标资产，执行 `预检`，确认 LOD、写入 UV 和输出路径后再烘焙。

不要对重要资产直接使用 `Overwrite Source`。测试和首次处理应优先生成副本，并在确认写入通道与结果后再决定是否覆盖源资产。

当前版本只把八面体编码的平滑法线方向写入一个 `float2` UV 通道。曲率会参与报告，但不写入资产，因此消费端无法据此补偿高曲率区域的视觉宽度不均；需要额外存储合同后再实现。
